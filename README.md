# FlowLab — ES 335 Project

FlowLab uses network-flow features to classify traffic as benign or one of seven attack types. The project compares five trained models and presents their results through interactive confusion matrices, test reports, and a flow inspector that runs predictions directly in the browser.

**Team:** Adusumilli Viraat Krishna (24110016) and Omer Mohammed Mubeenuddin (24110228)

## Dataset

[CIC-IDS-Collection on Kaggle](https://www.kaggle.com/dsv/4477547). The analysis uses the `cic-collection.parquet` file.

## Explore the project

- Open [index.html](index.html) in a browser to view the report and try the flow inspector.
- Open [ML_Evaluation.ipynb](ML_Evaluation.ipynb) for the data audit, model training, and evaluation.
